# NE능률 GEO 진단 v6

## 변경 사항 (v5 → v6) — API 의존성 완전 제거

Anthropic API 연동이 불가능한 상황에 맞춰 재설계했습니다.

- **서버/API 완전 삭제.** `/api` 폴더 자체를 없앴습니다. 이제 순수 정적 HTML 파일 한 개입니다. 서버리스 함수도, 환경변수도, API 키도 필요 없습니다.
- **채점은 100% 규칙 기반(로컬) 단일 경로.** AI 채점을 시도하고 실패하면 로컬로 전환하던 기존 구조를 없애고, 처음부터 규칙 기반 채점만 사용합니다. "채점 실패"라는 상황 자체가 발생하지 않습니다.
- **Claude 자동측정(API 반복 호출) 기능 삭제.** 대신 Claude도 ChatGPT·Perplexity·Gemini와 동일하게 "수동 캡처 엔진" 중 하나로 전환했습니다 — claude.ai에 직접 질문하고 답변을 복사해서 붙여넣는 방식입니다. 트랙 선택 화면에서 "Claude 추가" 체크박스로 켤 수 있습니다.
- **모든 문항이 확인 절차를 거칩니다.** 규칙 기반 채점이 유일한 판정 수단이므로, 채점 후 항상 결과 확인 화면이 뜨고 사람이 확인·수정한 뒤 저장해야 다음 문항으로 넘어갑니다. (v5까지는 "AI 채점은 자동 통과, 로컬만 확인" 구조였습니다.)

## 1. 배포 (매우 단순해졌습니다)

정적 파일 1개뿐이므로 배포 방법이 여러 가지입니다.

### 방법 A — Vercel (계속 쓰려면)
```bash
cd ne-geo-audit
git init && git add . && git commit -m "GEO 진단 v6"
git branch -M main
git remote add origin https://github.com/{계정}/ne-geo-audit.git
git push -u origin main
```
Vercel에서 Import → Framework Preset **Other** → Deploy. **환경변수 설정 불필요.**

### 방법 B — GitHub Pages (더 간단, 무료)
저장소 Settings → Pages → Source를 main 브랜치로 지정하면 끝입니다.

### 방법 C — 로그인 없이 그냥 파일로 공유
이 HTML 파일 하나를 그냥 이메일이나 사내 드라이브로 공유해서 더블클릭으로 열어도 100% 동작합니다. 네트워크 요청이 전혀 없으므로 인터넷 연결이 필요한 부분은 각 AI 서비스(ChatGPT 등) 접속뿐입니다.

## 2. 사용 흐름

1. 파일 열기(또는 배포 URL 접속) → **트랙 선택** — 로그인 없음
2. 측정 엔진은 기본 ChatGPT+네이버, 필요시 Claude·Perplexity·Gemini 체크박스로 추가
3. Step 1(환경 점검, 생략 가능) → Step 2(실측) → Step 3(진단) → Step 4(보고서)
4. Step 2에서 답변 붙여넣기 → **채점하기** 클릭 → 규칙 기반으로 즉시(네트워크 지연 없이) 판정 → 결과를 확인·수정 → **저장하고 다음**
5. Step 4에서 **보고서 저장**을 누르면 Step 5 「기록」 보관함에 남습니다

## 3. 로컬 채점기가 판정하는 것 / 사람이 확인해야 하는 것

| 자동 판정 (규칙 기반) | 사람이 확인 |
|---|---|
| 자사 브랜드 언급 여부 | **정보 오류** (개정연도·가격·구성 등 사실관계) — 이건 규칙으로 판정할 수 없어 항상 직접 확인 |
| 등장 순위 | |
| 회사명(NE능률/NE Build&Grow) 동반 여부 | |
| 자사 도메인 인용 여부 | |
| 경쟁사(국내 ELT 출판사 39종 + 해외 리더스 13종) 동시 노출 | |

경쟁사·자사 브랜드 사전은 `index.html` 안의 `OURS`, `COMP_G` 상수에 있습니다. 새 시리즈나 경쟁사가 나오면 이 목록에 추가하면 바로 반영됩니다.

## 4. 데이터 보관 범위 (중요, 변경 없음)

데이터베이스가 없습니다. 아래 두 가지는 **브라우저(localStorage)에만** 저장되며 다른 기기·브라우저에 동기화되지 않습니다.

- 측정 관측 데이터 (`ne_geo_state`)
- 저장된 보고서 보관함 (`ne_geo_reports`)

여러 명이 나눠서 측정한 경우, 각자 상단 **JSON 백업**을 받아 팀장님께 전달 → Step 1 하단 "다른 트랙 데이터 합치기"에 순서대로 붙여넣어 통합하십시오. 중요한 보고서는 Step 5에서 HTML로 다운로드해 별도 보관하십시오.
